## 5️⃣ 정책 관련 논의

- 같은 자동입찰 상한가일 때 누구를 우선할지?
    - 자동 입찰 예약 순 → 헤비 유저에게 우선권 (서비스 확장)
- 종료 직전 입찰 시 몇 분 연장할지
    - 내맘대로 (안중요함) → 나중에 수연 님께 알리기
- 상품 재경매를 몇 번 허용할지
    - 2번
- 최소 입찰 단위를 경매별로 둘지
    - YES + 수연 화면 추가 필요 (경매 올릴 때 설정할 수 있도록)
- 결제 기한
    - 24시간
- 차순위 이양을 몇 순위까지 할지
    - 3순위
- 2순위가 거절했을 때 페널티를 줄지
    - X
