## 1️⃣ 배포 직후 첫 상품 등록 지연 해결 공유

- 문제: 배포 직후 첫 상품 등록만 유독 느림
    - 원인: 서버가 뜬 뒤 첫 분석 요청이 Claude 연결 준비, 이미지 처리, S3 연결 비용을 한꺼번에 떠안음
- 해결: 서버가 뜨자마자 이 준비를 미리 해두는 워밍업 추가 (PR #133 머지 완료)
    - 첫 Claude 호출 8.0초 → 1.0초 (로컬 측정, 이후 호출과 같은 속도)
    - 비용: 배포 1번당 1원 미만
    - 배포 환경(api, worker)에서 자동으로 켜짐. 끄려면 `STARTUP_WARMUP_ENABLED=false`
- 확인 필요: 다음 배포 뒤 첫 등록이 실제로 빨라졌는지 확인

## 2️⃣ 사진 칸 즉시 확인 기능 공유 및 진행 여부 논의

- 문제: 지금은 사진 장수(3장)만 확인하고, 측면·앞면·밑창을 맞게 넣었는지는 보지 않음
    - 분석 단계에서 잘못 넣은 걸 알게 되면 분석 화면에서 1/6으로 되돌아가야 해서 흐름이 꼬임
- 제안: 사진을 칸에 넣는 순간 AI가 그 칸에 맞는 사진인지 바로 알려줌
    - 사진은 넣는 즉시 업로드 + 판정(약 1.5초). 사용자가 다음 사진을 고르는 동안 끝나서 따로 기다리는 시간은 없음
    - 사진이 미리 올라가 있어서 '다음'을 누른 뒤 업로드 대기 시간도 사라짐
- 칸 통과 기준
    - 측면·앞면 칸: 신발 윗부분이 보이면 통과 (각도는 따지지 않음)
    - 밑창 칸: 밑창 사진만 통과
    - 하자 칸: 판정하지 않음
    - 신발이 아닌 사진(박스, 라벨, 옷 등)은 어느 칸에서든 걸러냄
- 측정 결과 (실제 매물 사진 14장)
    - 정상 사진 12/12 통과, 밑창 4/4 맞힘, 밑창이 아닌데 밑창으로 판정 0장, 라벨·옷 2/2 걸러냄
    - 응답 평균 1.55초, 등록 1건당 약 1원
    - 표본이 작고, 깔창·눕힌 신발처럼 밑창과 헷갈리는 사진은 아직 확인하지 못함
- 현재 상태: AI 판정 부분은 main에 머지됨 (PR #134). 아직 API·화면에는 연결되지 않음
- 논의할 것
    - 이 기능을 진행할지
    - 진행한다면 경고가 떠도 '다음'으로 넘어가게 둘지 (AI 쪽 제안: 막지 않고 "그래도 진행할까요?" 확인 한 번)
- 진행할 경우 파트별 할 일 (상세는 "사진 칸 즉시 확인 작업 정리" 페이지 참고)
    - BE: 사진 1장 업로드 + 판정 API, 분석 요청을 사진 ID로 받기, 안 쓰인 사진 정리, API 서버에 `ANTHROPIC_API_KEY` 추가
    - FE: 칸에 넣는 즉시 업로드, 칸에 판정 결과(✓/경고) 표시, '다음' 누르면 사진 ID로 분석 시작
    - AI: 판정 전용 짧은 타임아웃 설정, API 서버 워밍업에 판정 모델 포함
