
## 0️⃣ 회의 안건

- Purchase Agent 사용자 가치 검증 방향 논의
- 기존 방식과 Agent 방식 비교 테스트 설계
- 사용성·신뢰도·추천 의향 평가 방법 정리
- 자동화 동작 및 경매 UX 확인 범위 정리
- 테스트 준비 및 TODO 정리

## 1️⃣ Purchase Agent 사용자 가치 검증 방향

- 최종발표·캡스톤 심사·면접에서 “기존 방식보다 무엇이 좋아졌는가?”에 답할 수 있도록 실제 사용자 테스트 결과 확보
- 사용자 연구 자체보다는 현재 구현된 기능의 가치를 간단히 검증하는 데 집중
- 검증 관점
    - 효율성: 직접 탐색·조작 부담이 줄어드는지
    - 사용성 및 신뢰: 기능을 이해하고 안심하며 사용할 수 있는지
    - 추천 의향: 다른 사람에게 추천할 만큼 가치가 있다고 느끼는지
- 경매 시스템은 기존 동시성·데이터 정합성·부하 테스트 결과 활용
- Purchase Agent는 기능 테스트와 사용자 비교 테스트를 함께 활용

## 2️⃣ 기존 방식 vs Purchase Agent 비교 테스트

- 참가자: 약 8~10명, 가능하면 중고거래 경험자 위주
- 동일 참가자가 두 방식 모두 사용
- 중고거래·경매 경험 여부 기록

### 비교 방식

- 기존 방식: 상품 직접 탐색 → 조건 확인 → 경매 선택 → AutoBid 설정
- Agent 방식: 구매 목표 입력 → 파싱 결과 확인·수정 → Goal 등록 → 자동 탐색 및 참여

### 테스트 시나리오 예시

> 뉴발란스 530, 270mm, A급 이상, 최대 15만 원으로 구매하고 싶습니다. 조건에 맞는 경매에 참여하도록 설정해 주세요.
> 

### 조건 통제

- 두 방식에 유사한 매물 수와 구매 목표 난이도 제공
- 참가자 절반은 기존 방식부터, 나머지는 Agent 방식부터 진행
- 진행자의 도움 여부와 내용 별도 기록
- 사용자 직접 작업시간과 Agent 자동 탐색 대기시간 구분
- 짧은 비교 테스트에서는 최초 설정 부담을 측정하고, 자동 재탐색은 별도 시나리오로 확인

### 측정 지표

| 항목 | 측정 기준 |
| --- | --- |
| 직접 조작 횟수 | 클릭·탭·입력 확정 등 의미 있는 조작 수. 마우스 이동·스크롤 제외 |
| 직접 확인한 경매 수 | 구매 판단을 위해 상세 정보를 확인한 서로 다른 경매 수 |
| 직접 소요 시간 | 기존 방식은 탐색 시작-> AutoBid 설정 완료, Agent는 목표 입력 시작-> Goal 등록 완료 |
| 작업 성공 여부 | 모델·등급·사이즈·예산이 요구 조건대로 설정됐는지 |
- Agent의 실제 자동 참여 성공 여부는 별도 확인
- 평균·중앙값 및 참가자별 감소율 비교
- 작업 성공률은 성공 인원 / 전체 참가 인원 × 100으로 계산
- 감소율: `(기존 방식 측정값 − Agent 방식 측정값) / 기존 방식 측정값 × 100`
- 참가자별 감소율의 평균과 전체 평균값 기준 감소율을 구분해 표기

## 3️⃣ 사용성·신뢰도 및 추천 의향 평가

### 공통 설문 — 각 방식 사용 후 5점 척도

- 상품 탐색과 구매 참여 준비 과정이 번거로웠다.
- 원하는 구매 조건을 설정하기 쉬웠다.
- 구매 참여를 준비하는 과정이 편리했다.
- 실제 서비스에서도 이 방식을 사용하고 싶다.

### Agent 추가 설문 — 5점 척도

- Agent가 내 구매 조건을 정확하게 이해했다고 느꼈다.
- Agent가 대신 경매에 참여하는 과정을 신뢰할 수 있었다.
- 자동입찰 시에도 예산과 참여 상태를 충분히 통제할 수 있다고 느꼈다.
- Agent가 어떤 경매에 참여했는지 이해하기 쉬웠다.
- 척도: 1점 전혀 그렇지 않다 ~ 5점 매우 그렇다
- 번거로움 문항은 낮을수록, 나머지 문항은 높을수록 긍정적으로 해석
- 문항별 평균 점수와 반복적으로 나타난 불편사항 정리

### 추천 의향 — 두 방식 체험 후

> Autique의 Purchase Agent 기능을 친구나 지인에게 추천할 의향이 얼마나 있나요?
> 
- 0점 전혀 추천하고 싶지 않다 ~ 10점 매우 추천하고 싶다
- 점수를 선택한 가장 큰 이유도 함께 수집
- NPS 계산
    - 9~10점: 추천 고객
    - 7~8점: 중립 고객
    - 0~6점: 비추천 고객
    - `NPS = 추천 고객 비율(%) − 비추천 고객 비율(%)`
- 소규모 참가자의 초기 추천 의향으로 제시하고 전체 사용자 평가로 일반화하지 않음

### 자유응답

- 기존 중고거래에서 가장 번거로웠던 점
- Agent가 실제로 대신해줬다고 느낀 과정
- 사용 시 불안하거나 불편했던 점
- 선호하는 방식과 이유
- 개선되었으면 하는 점

## 4️⃣ 자동화 동작 및 경매 UX 확인

### Purchase Agent 자동화 시나리오

- 구매 목표 등록 → 조건에 맞는 경매 탐색 → 후보 선택 및 AutoBid 등록
- 낙찰 실패 → 새로운 후보 탐색 및 재참여
- 낙찰 성공 → 구매 목표 종료 및 추가 참여 중단

### 확인 항목

- 사용자 조건에 맞는 경매 선택
- 예산 상한 준수
- 낙찰 실패 후 재탐색·재참여
- 낙찰 후 불필요한 추가 참여 중단
- 참여 및 결과 상태의 이해 가능성
- 테스트용 경매 데이터와 종료 시나리오 활용 가능
- 자동화 정확성과 상태 전이는 기능 테스트로 확인
- 짧은 사용자 테스트 결과를 장기 사용 편의성의 근거로 확대하지 않음

### 경매 UX 확인

- 현재가·내 입찰·최고 입찰 상태 구분
- 자동입찰 상한 의미 이해
- 마감 연장 규칙 이해
- 낙찰 여부 및 결과 인지

## 5️⃣ 최종발표 결과 구성

- 사용자 노력 감소
    - 직접 조작 횟수·확인한 경매 수·직접 소요 시간 비교
    - 작업 성공률 및 성공률 차이(%p) 제시
- 사용성 및 신뢰
    - 공통 설문 문항별 점수 비교
    - Agent 신뢰도·통제감 점수 제시
    - 대표 사용자 의견 및 개선 요구 정리
- 추천 의향
    - NPS와 추천·중립·비추천 고객의 인원 및 비율 제시
    - 추천하거나 추천하지 않은 주요 이유 정리
- 참가자 수·측정 범위·진행자의 도움 여부를 함께 명시
- 모든 결과 수치는 실제 테스트 완료 후 입력
