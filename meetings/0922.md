## 5️⃣ 프론트 추가 구현 논의

### 배경

- 사진 분석은 사진을 올리고 결과가 나오기까지 **약 11초**가 걸린다.
- 그동안 로딩 화면만 보여서 사용자와 시연 청중이 답답하게 느낀다.
- 백엔드는 분석이 한 단계 끝날 때마다 **잠정 결과**를 조회 응답에 이미 담아 보내고 있다. 프론트가 이 값을 화면에 표시하기만 하면 된다.

### 목표 화면

분석 중에 결과가 한 단계씩 채워지는 모습을 보여준다.

```
분석 중… (1/3)   →   나이키 · 덩크 로우 인식 (2/3)   →   상태 등급 B, 분석 완료
```

- 브랜드·모델이 먼저 뜨고, 상태 등급은 마지막에 채워진다.
- 시연에서 AI가 무엇을 하고 있는지 보여주는 장면이 되므로 눈에 잘 띄게 표시한다.

### 사용하는 API

기존과 같은 API를 쓴다. 새로 추가되는 API는 없다.

1. `POST /api/products/analyze`: 사진을 보내면 바로 `analysisId`를 돌려받는다.
2. `GET /api/products/analyze/{analysisId}`: 이 API를 **1초 간격**으로 조회한다.

### 조회 응답에서 볼 필드

| 필드 | 의미 | 언제 채워지나 |
| --- | --- | --- |
| `status` | 분석 진행 상태 | 항상 |
| `visionProgress.completedStages` / `totalStages` | 끝난 단계 수 / 전체 단계 수(3) | `VISION_PROCESSING` 중 1단계 이상 끝났을 때 |
| `preliminary.brand` / `modelName` / `color` / `size` | 잠정 결과 | 위와 같음 |
| `brand`, `modelName`, `conditionGrade` 등 | 최종 결과 | `AWAITING_USER_CONFIRMATION` 이후 |

`VISION_PROCESSING` 중 응답 예시는 다음과 같다.

```json
{
  "status": "VISION_PROCESSING",
  "visionProgress": { "completedStages": 2, "totalStages": 3 },
  "preliminary": { "brand": "Nike", "modelName": "Dunk Low", "color": "White/Black", "size": null },
  "brand": null,
  "conditionGrade": null
}
```

### 상태별 처리

| `status` | 화면 처리 |
| --- | --- |
| `CREATED`, `IMAGE_UPLOADED`, `QUEUED` | "분석 준비 중" 로딩을 표시한다 |
| `VISION_PROCESSING` | 진행 단계(n/3)와 `preliminary` 값을 표시한다 |
| `AWAITING_USER_CONFIRMATION` | 조회를 멈추고, 최종 결과로 기존 확인 화면을 띄운다 |
| `IMAGE_UPLOAD_FAILED`, `QUEUE_FAILED`, `VISION_FAILED` | 조회를 멈추고 에러 화면을 띄운다(`failureMessage` 참고) |

### 구현 시 주의사항

- **`preliminary`의 값은 null일 수 있다.** 세 단계가 동시에 돌아서 어느 단계가 먼저 끝날지는 매번 다르다. 1/3 시점에 브랜드가 비어 있을 수도 있으므로, null인 항목은 "인식 중…"처럼 표시한다.
- **잠정 값은 바뀔 수 있다.** 나중 단계나 최종 결과에서 브랜드·모델이 달라질 수 있다. 조회할 때마다 받은 값으로 화면을 덮어 갱신한다.
- **`size`는 라벨(택)을 읽는 단계가 끝나야 채워진다.** 사진에 택이 없으면 끝까지 null일 수 있다.
- **상태 등급은 잠정 결과에 없다.** `conditionGrade`는 최종 결과에서만 채워진다.
- **`VISION_PROCESSING`이 끝나면 `visionProgress`와 `preliminary`는 null로 내려온다.** 그 뒤로는 최종 결과 필드를 사용한다.
- **최종 결과 화면에서 브랜드·모델을 사용자가 확인하는 단계는 그대로 유지한다.** 모델명이 가격 조회 기준이라, AI가 틀린 경우 사용자가 바로잡을 수 있어야 한다.
