## 1️⃣ 현재 가격 계산 방식
    
**① 당근 시세가 있는 경우 (1순위)** 
    
색상 근거를 3단으로 다시 좁힙니다:
    
1. **같은 색상 계열 버킷이 있으면** (`used_market_prices_by_color.csv`, 표본 10건 이상) 그 버킷의 median/Q1/Q3를 그대로 씀
2. **없으면 KREAM 색상 프리미엄으로 보정** — 당근 모델 시세 × (KREAM에서 이 색이 모델 평균 대비 몇 배). 프리미엄이 [0.5, 2.0] 밖이면 콜라보·한정판 혼입으로 보고 버림
3. **그것도 없으면** 모델 전체 시세
    
그 다음 상태·구성품 반영:
    
- 상태는 **절대 계수가 아니라 비율**입니다: `gradeRate / ALL등급 계수`. 시세 중앙값이 상태 불문 전체 매물에서 나왔으니 분모도 ALL이어야 함. 등급 계수가 모델 전용 실측이면 분모도 같은 모델의 ALL을 씀 (감가 속도가 모델마다 달라서 — 에어포스1 0.44 vs 993 0.61)
- 상태 UNKNOWN이면 비율 **1.0 고정**. UNKNOWN 계수를 적용하면 "판매자가 안 적음"과 "Vision이 못 읽음"이 같은 신호가 되어버려서
- 구성품: FULL 1.00 / PARTIAL 0.97 / NONE 0.95 / 미상 0.97
- **권장 범위는 ±5%가 아니라 실거래 IQR(Q1~Q3)** 에 같은 계수를 곱한 값
- 응답의 `kreamAveragePrice`/`ebayAveragePrice`는 **0으로 비워** 이 경로가 KREAM을 안 썼다는 걸 드러냄
    
**② 당근에 없고 크림에만 있는 경우 (2순위)**
    
- 매칭 조건이 훨씬 빡빡합니다: 브랜드 일치 + 모델 양방향 포함 + **컬러웨이 양방향 포함 + 사이즈 정확 일치**
- `KREAM 평균 × 상태계수(절대값) × 구성품계수`, 범위는 **±5%**
- 여기 오면 "중고 시세 미보유(2순위 폴백)" 로그가 남습니다 — 커버리지 확대 우선순위 근거로 쓰려고
    
**③ 당근·크림 둘 다 없고 eBay만 있는 경우**
    
`recommendedPrice = 0` → **시세 없음**. eBay 매칭 목록과 평균가는 응답에 실어주되 "국내 실거래와 차이가 커 추천가 근거로 쓰지 않았다"는 문구를 붙입니다. 틀린 값보다 없음이 낫다는 원칙. (현재 데이터에는 eBay 전용 모델이 실제로 없어서 도달하지 않는 분기)
    
**④ 아무데도 없는 경우** — "시세 정보 없음" + "시세 정보 없음 응답" 로그
    
### AI 트랙에서의 소비
    
PricingServiceEstimateProvider.java:33가 위 결과를 `PriceEstimate`로 옮깁니다. 새 계산식은 없고 보정 하나만 있습니다:
    
- 호출 전 **별칭 표(ModelAliases)로 접어서** 물어봄. Product.model이 Vision 초안 기반 자유 텍스트("덩크 로우", "990v6")라 CSV 표기와 문자로 안 맞는 걸 카탈로그 표기("Dunk Low")로 살림. 별칭 표가 모르면 원문 그대로
- `recommendedPrice <= 0` → `Optional.empty()`, 즉 **시세 없음은 null로 전파**
- `source` 판별은 `kreamAveragePrice > 0`이면 KREAM, 아니면 USED_MARKET (1순위가 KREAM 필드를 0으로 비우는 성질을 이용)
- KREAM 경로는 IQR이 없어 min/max가 0일 수 있어서 추천가로 채움 → lower == upper == estimated면 "범위 없음"
- 경매 상세(AuctionQueryService.java:157)는 `Product.recommendedPrice`(판매자가 보낸 클라이언트 값)를 **안 쓰고** 이 서버 계산값을 씁니다. 계산이 터져도 경매 조회는 살아야 하니 예외는 삼키고 null
    
### 한 줄 요약
    
당근 실거래 > (색상 버킷 > KREAM 색상 프리미엄 > 모델 전체) → 없으면 KREAM 평균 × 상태계수 → 없으면 시세 없음. eBay는 참고만, 판단 못 하면 숫자를 만들지 않고 null.
