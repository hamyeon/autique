## 1️⃣ 사용자 테스트 목적 및 진행 방식 논의

- 테스트 목적
    - Autique가 판매자의 상품 가격 결정 부담을 실제로 줄이는지 검증
    - 구매 Agent가 구매자의 반복적인 상품 탐색 및 입찰 부담을 줄이는지 검증
    - AI 가격 추천의 유용성과 구매 Agent에 대한 사용자 신뢰도 확인
    - 실제 사용자 평가를 통해 서비스의 핵심 가치 및 개선점 도출
- 테스트 대상 및 진행 방식
    - 개발에 참여하지 않은 외부 사용자 8~10명 모집
    - 진행자 1명과 참가자 1명이 개별적으로 테스트 진행
    - 참가자 1명당 약 10분 소요 예정
    - 직접 서비스 체험 + 진행자 측정 + 최종 설문 방식으로 구성
    - 기존 중고거래 플랫폼과 Autique를 동일한 참가자가 모두 체험하는 비교 방식 적용
- 핵심 검증 질문
    - AI 가격 추천이 직접 시세를 조사하는 것보다 빠르고 편리한가?
    - 구매 Agent를 이용하는 것이 직접 매물을 탐색하는 것보다 부담이 적은가?
    - 사용자가 구매 조건과 예산을 설정한 뒤 자동입찰을 Agent에게 위임할 의향이 있는가?

## 2️⃣ AI 가격 추천 사용자 테스트 설계

- 테스트 목적
    - 기존 중고거래 플랫폼에서 직접 시세를 조사하는 방식과 Autique의 AI 가격 추천 방식 비교
    - 가격 판단에 필요한 시간과 사용자 편의성 측정
    - 추천 가격 및 산정 근거가 실제 가격 결정에 도움이 되는지 확인
- STEP 1: 신발 A의 판매 가격 예상
    - 참가자에게 테스트용 신발 A를 보여주고 검색 없이 적정 판매 가격을 예상하도록 요청
    - 시세 조사 및 AI 가격 추천 이전의 가격 판단 기준 확인
    - 참가자가 예상한 판매 가격 기록
- STEP 2: 기존 플랫폼에서 직접 시세 조사
    - 참가자가 평소 이용하는 중고거래 플랫폼에서 유사 매물 검색
    - 상품 상태 및 가격을 비교하여 적절한 판매 가격 결정
    - 최대 조사 시간을 2분으로 제한
    - 측정 항목: 이용 플랫폼, 조사 소요 시간, 결정 가격, 참고 매물 수, 제한 시간 내 가격 결정 성공 여부
    - 제한 시간 내 가격을 결정하지 못한 경우 실패로 기록하고 다음 단계 진행
- STEP 3: Autique 상품 등록 및 가격 추천
    - 동일한 신발 A의 사진을 Autique에 등록
    - AI 상품 분석 결과 확인 및 필요시 수정
    - AI 추천 가격과 가격 산정 근거 확인
    - 측정 항목: 추천 가격 확인까지의 소요 시간, 분석 정보 수정 여부, AI 추천 가격, 제한 시간 내 완료 여부
- 비교 및 분석 방향
    - 기존 방식과 Autique의 소요 시간 및 제한 시간 내 완료율 비교
    - 최초 예상 가격, 직접 조사 후 결정 가격, AI 추천 가격 비교
    - AI 추천 가격과 산정 근거가 가격 결정에 미치는 영향 확인
    - 가격 결정 편의성에 대한 사용자 선호도 조사
    - 추천 가격 자체의 정확도를 검증하는 실험과 사용자 편의성을 검증하는 실험은 구분

## 3️⃣ 구매 Agent 사용자 테스트 설계

- 테스트 목적
    - 기존 플랫폼의 직접 상품 탐색 방식과 구매 Agent의 자연어 기반 구매 목표 설정 방식 비교
    - 구매자가 상품을 탐색하고 조건을 설정하는 과정에서 필요한 시간 및 조작 횟수 측정
    - AI의 구매 조건 해석 및 경매 매칭 결과 확인
    - 반복 탐색과 자동입찰에 대한 사용자의 기대 가치 및 위임 의향 확인
- STEP 4: 기존 플랫폼에서 직접 상품 탐색
    - 참가자에게 신발 B의 구매 조건이 적힌 카드 제공
    - 구매 조건 예시: 아식스 노바블라스트, 270mm, A급 이상, 최대 15만 원
    - 실제 테스트 매물에 맞춰 모델·사이즈·상태·예산 조건 설정
    - 참가자가 평소 이용하는 플랫폼에서 조건에 맞는 상품을 검색하고 구매하고 싶은 매물 1개 선택
    - 최대 탐색 시간을 2분으로 제한
    - 측정 항목: 탐색 소요 시간, 검색·필터 조작 횟수, 상세 확인 매물 수, 조건에 맞는 매물 발견 여부, 선택 매물 가격
    - 제한 시간 내 조건에 맞는 매물을 찾지 못한 경우 발견 실패로 기록
- STEP 5: 구매 Agent PIKI 체험
    - 동일한 구매 조건을 자연어로 직접 입력하도록 안내
    - AI가 해석한 모델·사이즈·상태·예산 확인
    - 필요한 경우 구매 조건 수정 후 Goal 등록
    - Agent가 선택한 경매 및 AutoBid 등록 결과 확인
    - 측정 항목: Goal 등록까지 소요 시간, 조건 해석 일치 여부, 조건 수정 횟수, 경매 선택 및 AutoBid 등록 성공 여부
    - 구매 조건 해석 결과는 전부 일치 / 일부 수정 필요 / 불일치로 구분
    - 자동입찰 결과를 확인하지 못한 경우 실패와 구분하여 '확인 불가'로 기록
- 낙찰 실패 후 재탐색 추가 시연
    - 제한된 테스트 시간 내 전체 경매 및 재탐색 과정을 직접 체험하기 어려울 수 있음
    - 낙찰 실패 후 Agent가 다른 경매를 재탐색하는 과정은 사전에 준비한 결과 화면 또는 영상으로 설명
    - 참가자가 직접 체험한 기능과 시연으로만 확인한 기능을 구분하여 평가
- 비교 및 분석 방향
    - 직접 상품 탐색과 Agent 초기 설정에 필요한 시간 비교
    - 검색·필터 및 구매 조건 설정 과정의 사용자 조작 횟수 비교
    - 자연어 입력을 통한 구매 조건 해석 및 경매 매칭 결과 확인
    - Agent가 반복적인 탐색과 입찰 부담을 줄여줄 것이라고 느끼는지 조사
    - 실제 입찰 완료 시간과 Goal 등록 소요 시간은 별도로 기록
    - 직접 상품 탐색 완료와 Agent 초기 설정 완료가 동일한 작업은 아니라는 점을 결과에 명시

## 4️⃣ 사용자 설문 및 진행자 기록지 구성

- 최종 설문 구성 (총 7문항)
    - Q1. 판매 가격 결정 방식의 편의성 비교 (직접 시세 조사 / Autique / 비슷함)
    - Q2. AI 추천 가격 및 산정 근거의 도움 정도 (5점 척도)
    - Q3. 상품 탐색 방식의 편의성 비교 (직접 탐색 / Purchase Agent / 비슷함)
    - Q4. 구매 Agent의 반복적인 상품 탐색 및 입찰 부담 감소 기대 (5점 척도)
    - Q5. 구매 Agent에 자동입찰을 위임할 의향 (5점 척도)
    - Q6. 실제 중고 신발 구매 시 선호하는 구매 방식
    - Q7. Autique에서 가장 편리했던 점과 우려되거나 아쉬웠던 점 (자유응답)
- 설문 설계 방향
    - 가격 추천과 구매 Agent에 대한 평가를 하나의 설문으로 통합
    - 정량적 평가를 위한 선택형 문항 및 5점 척도 활용
    - 정성적 의견을 수집하기 위한 자유응답 문항 포함
    - 직접 체험한 편의성과 향후 사용에 대한 기대·위임 의향을 구분하여 분석
- 진행자 기록지 구성
    - 판매 가격 결정 및 추천가 확인 소요 시간
    - 제한 시간 내 가격 결정 및 추천가 확인 성공 여부
    - 참가자의 결정 가격 및 AI 추천 가격
    - 상품 탐색 및 Agent 초기 설정 소요 시간
    - 검색·필터·조건 설정 등 사용자 조작 횟수
    - 구매 조건 반영 및 매물 선택 성공 여부
    - 테스트 중 진행자의 도움 제공 여부
- 측정 기준
    - 참가자가 직접 시간을 측정하지 않고 진행자가 측정
    - 제한 시간 내 완료하지 못한 경우 실패 여부와 제한 시간 도달 사실을 함께 기록
    - Goal 등록 완료 시간과 실제 경매 탐색 및 입찰 완료 시간을 구분
    - 측정하지 못한 값은 추정하지 않고 '측정 못함'으로 기록
    - 참가자별 진행자 안내 및 도움 제공 기준을 최대한 동일하게 유지
    - 시간 측정의 시작·종료 시점과 조작 횟수 집계 기준을 사전에 통일
- 테스트 설계의 한계
    - 기존 플랫폼과 Autique의 매물 구성 및 데이터 환경이 다를 수 있음
    - 기존 플랫폼에서의 가격 조사 경험이 이후 Autique 평가에 영향을 줄 수 있음
    - 직접 탐색 완료와 Agent 초기 설정 완료는 서로 다른 작업이므로 단순한 전체 구매 시간 비교로 해석하지 않음
    - 사전 등록된 테스트 경매를 활용하므로 실제 서비스 환경에서의 매물 탐색 성공률과 구분
    - 소규모 사용자 테스트이므로 전체 사용자에 대한 일반화보다 초기 사용성 및 서비스 가치 확인에 집중

## 5️⃣ 테스트 결과 분석 및 졸업발표 활용 방법 논의

- AI 가격 추천 관련 분석 지표
    - 직접 시세 조사와 Autique의 제한 시간 내 완료 인원 및 완료율
    - 각 방식의 완료자 평균 소요 시간
    - 참가자의 직접 결정 가격 및 AI 추천 가격
    - AI 가격 추천 방식의 편의성 선호도
    - 추천 가격 및 산정 근거의 도움 정도
- 구매 Agent 관련 분석 지표
    - 직접 탐색과 Agent 초기 설정의 제한 시간 내 완료율
    - 각 방식의 완료자 평균 소요 시간 및 사용자 조작 횟수
    - 구매 조건 해석 일치율 및 수정 필요 여부
    - 조건에 맞는 경매 선택 및 AutoBid 등록 성공 여부
    - 구매 Agent 방식의 편의성 선호도
- 사용자 선호도 및 신뢰도 분석 지표
    - AI 가격 추천 선호 인원 및 비율
    - Purchase Agent 선호 인원 및 비율
    - 가격 추천 도움 정도 평균 점수 (5점 만점)
    - 구매 Agent의 탐색·입찰 부담 감소 기대 평균 점수 (5점 만점)
    - 자동입찰 위임 의향 평균 점수 (5점 만점)
    - 실제 구매 시 선호하는 방식
    - 자유응답에서 나타난 주요 장점 및 우려 사항
- 결과 분석 방향
    - 시간 및 조작 횟수 감소와 같은 정량적 결과와 사용자 체감 편의성을 함께 분석
    - 가격 추천과 구매 Agent 중 사용자가 더 큰 가치를 느끼는 기능 확인
    - 자동입찰 위임을 주저하는 이유와 실제 서비스 이용을 위해 필요한 개선 사항 도출
    - 완료자 평균 소요 시간은 완료율과 함께 제시하여 해석상의 오류 방지
    - 직접 체험 결과와 영상 시연을 바탕으로 응답한 기대 효과를 구분
    - 테스트 결과가 예상과 다르더라도 실제 측정값을 그대로 반영
- 졸업발표 및 포스터 활용
    - 기존 방식과 Autique의 비교 결과를 표 또는 그래프로 시각화
    - 판매자 및 구매자의 문제 해결 여부를 사용자 테스트 결과와 연결
    - 핵심 정량 지표와 대표 사용자 의견을 포스터에 반영
    - 참가자 수, 테스트 과제, 제한 시간 및 측정 기준을 함께 표기
    - 기존 기술 성능 평가와 별도로 실제 사용자가 느끼는 서비스 가치 제시
    - 테스트 완료 후 실제 결과를 바탕으로 최종 발표 문구 확정
